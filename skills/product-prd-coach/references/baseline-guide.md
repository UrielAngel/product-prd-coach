# 基准文件（Baseline）指南

阶段 B 加载本文件。基准文件是本 skill 防越界机制的基础设施：**没有基准文件，AI 就会在需求未描述处自行编造。**

## 一、基准文件是什么

一个描述"产品现在是什么样"的本地事实源。AI 动笔前读它，产出的新功能才能与现状衔接；需求没说到的地方，也从它这里继承而不是发挥。

它解决的是迭代需求的核心矛盾：**PM 脑子里装着产品全貌，AI 只看到用户这一句话。** 不上基准文件，每次迭代都要重新给 AI 解释一遍已有功能和交互风格——这是 PM 用 AI 做需求时最大的时间黑洞。

## 二、目录结构

放在项目根目录下：

```
baseline/
├── product-overview.md      产品概述：定位、核心价值、用户角色、业务版图
├── feature-inventory.md     功能清单：模块 → 子功能 → 关键规则
├── interaction-spec.md      交互规范：组件用法、状态定义、文案风格、视觉基调
└── glossary.md              术语表：业务术语与技术口径的统一定义
```

小产品可合并为单个 `baseline/product-baseline.md`；模块超过 15 个时按业务域拆分为 `feature-inventory-<域>.md`。

## 三、各文件要点

### product-overview.md
定位一句话、核心用户角色（含权限差异）、主要业务流程全景、产品版本与迭代节奏。

### feature-inventory.md（最关键的防越界资产）
按模块组织，每个子功能记录：**功能名 / 入口 / 前置条件 / 主逻辑 / 异常与边界 / 关联功能**。颗粒度以"另一个 PM 读完能接手维护"为准。

> 这里是 AI 复用规则的来源。写得越具体，后续 PRD 的"沿用 XX 既有规则"就越可信、越少待确认项。

### interaction-spec.md
通用组件的使用约定（列表的默认排序与分页、表单的校验时机、弹窗的确认逻辑）、各状态的展示规则（空态文案模板、加载态、失败态、无权限）、文案语气（如"动词开头、不用感叹号、不出现'亲'"）、视觉基调（主色、间距节奏、圆角）。

### glossary.md
统一术语，避免同一概念在 PRD 里出现多种叫法。每条记录：术语 / 定义 / 别名 / 使用注意。

## 四、冷启动引导（新用户）

**不对用户自动抓取任何远程内容**（隐私与内网不可达都是硬约束）。取而代之：先让用户理解价值，再给低门槛入口。

引导话术结构：

1. **先说收益**：告知"提供基准材料后，AI 产出的 PRD 越界率会显著下降——需求没写到的部分会按你产品的既有规则继承，而不是胡编。这一步大约占 10 分钟，会换来后续每次迭代都少解释一遍。"
2. **再给三个入口，让用户任选其一**（不必三个都做）：
   - **截图**：线上已有功能的页面截图，AI 识别现状生成 feature-inventory 与 interaction-spec 初版
   - **链接**：产品官网或网页版链接（**明确告知：仅公开可访问时有效，内网地址请改用截图**）
   - **文字说明模板**：提供结构化空白模板，用户按项填空
3. **允许跳过**：用户明确表示暂不提供时，进入降级模式——全部未知项一律落入「待确认」，并在 PRD 附录集中列出。**不使用没有依据的默认假设。**

生成的初版基准文件必须让用户确认后才落盘，并提示"这份文件可以长期使用，后续每次迭代都会反哺更新"。

## 五、反补规则（每次产出后必做）

迭代 PRD 完成后，新增/变更的内容必须回写基准文件，顺序：

1. 本次新增的功能 → 补入 feature-inventory
2. 本次新确立的交互规则 → 补入 interaction-spec
3. 首次出现的术语 → 补入 glossary
4. 推翻了旧逻辑的 → **标注废弃原因与变更版本**，不直接删除（保留演进轨迹）

**反补发生在 PRD 定稿之后、交付之前。** 未反补等于下次迭代要重新解释一遍，前功尽弃。

## 六、飞轮：HTML 原型即下一轮基准

阶段 2 产出的 HTML 原型是产品改版后的真实形态，它比官网链接更准。

每次交付后把 HTML 原型归档到 `docs/prototypes/<版本>/`，下次迭代时它就是最新的事实源。**每一轮交付都在自动喂养下一轮**，基准文件的维护成本随迭代递减。

## 七、边界

以下**不应**写入基准文件：本期需求的方案内容（那是 PRD 的事）、未确定的猜测、临时性配置。

基准文件记录的是"已确定为真的事实"，不是"待办的想法"。混入猜测会污染后续所有产出。
