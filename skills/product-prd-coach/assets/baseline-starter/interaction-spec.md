# 交互规范模板

> 斜体为虚构示例，请替换为你的真实规范。

## 通用组件约定

| 组件 | 约定 |
|------|------|
| 通用列表 | _默认按时间倒序；每页 20 条下拉加载更多；不显示总数_ |
| 表单校验 | _失焦即校验，不等待提交；错误信息显示在输入框下方，红色 12px_ |
| 主操作按钮 | _位于页面底部固定悬浮/单页内的右上角；同一页面只允许一个主色按钮_ |
| 弹窗 | _二次确认弹窗必须说明后果（如"删除后 7 天内可恢复"）；标题动词开头，不用问句_ |
| 返回 | _编辑态返回时若内容有改动，弹「保存/放弃」二选一，不允许三级弹窗嵌套_ |
| Toast | _停留 2 秒，位于屏幕中偏下，同一时间只允许一条_ |

## 状态定义

| 状态 | 统一表现 |
|------|----------|
| 空态 | _居中插图 + 主文案说明"还没有XXX" + 一句引导文案 + 次级按钮引导动作；不使用纯文字留白_ |
| 加载态 | _首屏骨架屏，非首屏用局部 loading；加载超 3 秒显示"网络较慢"提示_ |
| 失败态 | _居中图标 + 文案「加载失败」+「重新加载」按钮；不自动重试_ |
| 无权限 | _整页提示「你没有访问权限」+「申请权限」按钮_ |
| 极值态 | _超长文本两行截断加省略号，不换行撑开；金额超宽自动缩字号，不折行_ |

## 文案风格

- _动词开头：「查看报表」而非「报表」_
- _不使用感叹号；不使用「亲」「哦」等语气词_
- _金额一律带两位小数并右对齐；负数用红色_
- _错误文案说清「怎么改」，不只说「错了」：如「金额不能超过 9,999,999」_

## 视觉基调

- _主色 #4A6CF7，危险色 #E5484D_
- _圆角统一 8px（卡片）/ 22px（按钮）_
- _移动端基准宽度 390px_
- _次级文字 #8A8F99，禁用态透明度 0.4_

## 动效

- _页面转场：右侧推入，300ms_
- _列表删除：向左滑出的同时下方内容上移，250ms_
- _不使用弹性回弹过头的动效_
