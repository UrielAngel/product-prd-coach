## 模块：_记账_

### _快速记一笔_

| 项 | 内容 |
|----|------|
| 入口 | _首页底部中央的悬浮「+」按钮，支持长按唤起_ |
| 前置条件 | _已登录；至少存在一个账本_ |
| 主逻辑 | _步数控制在 3 步内：金额 → 分类 → 保存。默认读取上次使用的账本与账户_ |
| 异常与边界 | _金额为 0 或未填写时「保存」置灰；超过上限（9,999,999）时输入框下方红字提示；断网时写入本地队列，联网后自动补传并在首页 toast 提示_ |
| 关联功能 | _保存成功后 → 更新账本余额 → 触发预算检查 → 超支时弹出提醒_ |

### _账单详情编辑_

| 项 | 内容 |
|----|------|
| 入口 | _首页流水列表点击任意一条 → 详情页 → 右上角「编辑」_ |
| 前置条件 | _账单未被删除；非跨月锁定状态_ |
| 主逻辑 | _可修改金额、分类、备注、时间；修改后即时更新对应统计_ |
| 异常与边界 | _跨账单 Avatar 不支持修改金额项；删除后 7 天内可在「最近删除」恢复_ |
| 关联功能 | _删除后回退账本余额与预算占用_ |

## 模块：_预算_

### _月度预算设置_

| 项 | 内容 |
|----|------|
| 入口 | _我的 → 预算管理 → 右上角「设置」_ |
| 前置条件 | _本月无进行中的预算，或用户选择「覆盖当前预算」_ |
| 主逻辑 | _设置总额，可选按分类设置子预算；本月剩余天数 < 7 时提示是否计入下月_ |
| 异常与边界 | _总额为 0 视为不限；子预算之和超过总额时给出警告但允许保存_ |
| 关联功能 | _触发超支提醒规则（见「预算提醒」）_ |
